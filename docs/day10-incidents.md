# Day10：告警事务（故障与通知）

## 1. 目标和边界

Day10 在 Day09 的状态结果之上实现故障生命周期：连续两次失败打开 incident 并发送告警邮件；恢复关闭 incident 并发送恢复通知。`incidents` 一个监控最多一个未恢复故障；`notifications` 记录站内与邮件投递，用去重键防止重复发送。

Issue：`[PW-009] 完成告警事务`。建议分支：`feat/PW-009-incidents`。

## 2. 故障

- 连续两次失败打开 incident。
- 同一监控未恢复故障唯一（数据库约束保证）。
- 恢复后关闭 incident，记录 `resolved_at`。

## 3. 通知

- 告警邮件与恢复邮件，本地走 Mailpit，生产走 SMTP。
- 站内通知记录，去重键防重复投递。
- 邮件发送失败记录错误，不阻塞状态机。

## 4. 验收证据

必须通过：

1. `cd server && go test -race ./...`，含连续失败开故障、恢复关故障、去重、未恢复唯一约束、事务回滚用例；
2. 本地 Mailpit 收到告警与恢复邮件。

## 5. 明确不包含

SSE 提示（Day11）、Webhook、自定义邮件模板、邮箱验证/找回密码。
